# 命令行界面（pet-cli）

ratatui 全屏终端界面，与桌面 GUI 共享同一套 `config.yaml`、会话、记忆和群聊状态，
两者可同时运行（每轮发送前都会从磁盘重载会话，互不覆盖）。定位是轻量子集：
单 Agent 聊天、Agent/模型/会话切换、多 Agent 群聊；配置、心跳、Telegram 仍在 GUI 里管理。

## 运行

```bash
cargo run -p pet-cli            # 交互 TUI
cargo run -p pet-cli -- -p "帮我看下这个目录"   # 单次执行：输出回复后退出
```

## 命令

输入 `/` 会弹出命令面板：↑↓ 选择，Enter/Tab 确认，Esc 关闭。

| 单聊 | 说明 |
| --- | --- |
| `/agents` | 选择并切换 Agent（↑↓ 选择，Enter 切换） |
| `/models` | 从 API 拉取模型列表，选择并切换当前 Agent 的模型 |
| `/sessions` | 选择并切换会话（切换后回放最近几条到屏幕） |
| `/new` | 新建会话 |
| `/tasks` | 查看后台任务（只读列表） |
| `/group` | 进入多 Agent 群聊 |
| `/help` `/quit` | 帮助 / 退出 |

| 群聊 | 说明 |
| --- | --- |
| `/members` | 选择群成员（Space 勾选，Enter 应用） |
| `/pause` `/resume` | 暂停 / 恢复所有 Agent |
| `/reset` | 清空群聊记录（保留成员） |
| `/history [n]` | 回放最近 n 条群聊记录 |
| `/back` | 返回单聊（群聊后台继续） |

列表命令都以浮层展示（同命令面板交互），不会把输出灌进聊天记录。

## 按键

| 按键 | 作用 |
| --- | --- |
| Enter | 发送 / 确认面板选择 |
| ↑↓ | 面板/浮层内选择；输入非空时翻输入历史；**输入为空时**在可展开条目间移动 |
| Enter（有选中条目时） | 展开 / 收起工具调用或思考过程 |
| Ctrl+O | 快捷展开/收起最近一个可展开条目 |
| PgUp / PgDn | 滚动聊天历史（回到底部后自动跟随） |
| Esc | 关闭面板/浮层；取消条目选中 |
| Ctrl+C | 清空输入；输入为空时退出 |

## 展示

- 回复按 **Markdown 渲染**（标题/粗斜体/行内码/代码块/列表/引用/链接），流式生效。
- **工具调用**默认折叠为单行摘要，可展开看完整参数与结果；思考过程（reasoning）同理。
- 底部状态栏：当前模式 · Agent · 模型 · 上下文用量（含百分比）· 可用工具数。
- 群聊里打印各成员的最终发言与工具调用轨迹；并发的 token 流不直接上屏。
- 后台任务（长命令 / 子代理）完成后自动注入对话并继续，与 GUI 行为一致。

## 局限

- 未开鼠标捕获（保留终端原生选择/复制），滚动用 PgUp/PgDn。
- 流式过程中无法取消当前轮（与 GUI 一致）。
- MCP 服务器按需连接：某 Agent 首次发言前才启动它配置的 MCP。
